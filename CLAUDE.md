# Project: "Tools By Sanat" Excel add-in

Turn the macros in Sanat's `PERSONAL.XLSB` into a single installable Excel add-in (`.xlam`) with a custom ribbon tab, custom icons, an easy installer, and online updates from GitHub.

> This is NOT a Laravel project. Ignore any Laravel/Sail notes from a parent-folder CLAUDE.md (e.g. `Downloads\CLAUDE.md`).

- Ribbon tab **"Tools By Sanat"** with groups **HA**, **DMS TATA**, **Reliance** (reference screenshot: tab with buttons such as Cmp Wise Sale Register (Detail), DABUR E-INVOICE, Sale Comp, IRN Upload Format, Collection Outstanding Report Setup, Van_Wise Outstanding Report, Keep Only Highlighted Cell Rows, Fill Down Blanks, Party Wise Receiving Summary, E Invoice Validation, Dabur Sale Fromat HA, Password Breaker, Stkreport.Wisdom_Stkreport, Convert Selected Cells, Combine Header And Clean, Marico Hide Unwanted Columns, Flipkart PO Formatter, Blinkit PO Format; DMS TATA: Customer Wise Sale Detail DMS, DMS HSN Summary, DMS Stock Statement, E Invoice Format DMS MAX; Reliance: SRM Po Excel, Print_Setup, RIL Po To Excel, Process For Amendment, Insert Brand Name ASN, RIL Appointment, RIL_Appointment_Auto). Confirm the exact button-to-macro mapping with the user.
- Easy install on any Windows PC; new tools delivered by online update.

## Decisions made
- Format: `.xlam` add-in, Windows desktop Excel only (no Mac / Excel web).
- Ribbon: `customUI14.xml` inside the `.xlam`; custom PNG icons (about 32x32, transparent) via `getImage` callback, `imageMso` as fallback for buttons without a custom icon.
- Macros are stored inside the `.xlam` (compiled `vbaProject.bin`). Keep exported source (`.bas/.cls/.frm`) in `src/` as the source of truth.
- Install on a PC: `install.ps1` (plus a double-click `Install.bat` wrapper) copies the file to `%APPDATA%\Microsoft\AddIns`, unblocks it, registers it in Excel. Manual fallback: unblock file, File > Options > Add-ins > Browse.
- Online updates via **GitHub** (user's choice), loader + main add-in design:
  - Small `ToolsBySanatLoader.xlam` is installed once and rarely changes.
  - Main `ToolsBySanat.xlam` lives next to the loader in `%APPDATA%\Microsoft\AddIns` (a folder Excel trusts by default); `ToolsBySanat_data\pending` and `\prev` hold the staged update and the rollback copy. Only the loader is registered in Excel.
  - On Excel start the loader fetches `version.json` (raw.githubusercontent.com), and if newer, downloads the `.xlam` from the GitHub Release, verifies SHA-256, swaps the file BEFORE opening it (Excel locks loaded add-ins), then loads it. On any failure keep the old version and stay silent. Keep the previous version for rollback.
  - Ribbon has a version label and a "Check for updates" button.
  - HTTPS only; hash check required.

## Known risks to check when porting macros
- References to `ThisWorkbook`, `Workbooks("PERSONAL.XLSB")`, or sheets stored in PERSONAL.XLSB break in an add-in. Scan and fix (use `ActiveWorkbook`/`ActiveSheet`, or add-in-specific storage).
- Keyboard shortcuts (`Application.OnKey`/macro options) must be reassigned.
- UserForms export as `.frm` + `.frx`; keep both.
- Macros calling `Application.Run "PERSONAL.XLSB!Name"` need updating.
- Corporate PCs may block downloads/macros; updater must fail silently and keep the old version.

## Build notes
- Building the `.xlam` (injecting VBA via COM from PowerShell) needs Excel option "Trust access to the VBA project object model" enabled on the BUILD PC only. End users do not need it.
- Excel must be closed when replacing an installed `.xlam` (file lock).
- Never run host installs/uploads silently: do not `git push`, create a GitHub repo, or publish releases without the user's explicit OK.
